# Defender Repair Lab

A Defender-lite game built using **Pygame**. This project focuses on debugging, world-space and screen-space coordinates, camera wrapping, radar visualization, and implementing additional game features using an AI-assisted coding approach.

---

## Project Overview

The project is a single-file Defender-lite game.

The game includes:

- A player ship
- A wrapping game world
- Humanoids on the ground
- Lander enemies
- Mutant enemies
- A radar showing objects across the game world
- Waves
- Lives
- Scoring
- Humanoid rescue mechanics

The original project contained:

- One deliberate radar coordinate-system bug
- Three optional functions that were left incomplete

The objective was to analyze the existing code, use an AI assistant as a debugging and pair-programming partner, implement the required changes, and demonstrate the results through gameplay videos.
